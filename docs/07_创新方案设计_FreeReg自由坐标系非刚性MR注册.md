# 创新方案设计 —— FreeReg: 自由坐标系下的非刚性混合现实注册框架

> **定位**: 面向期刊投稿的完整研究方案设计 (目标期刊分析见 docs/08)
> **思路来源**: 用户核心思想 —— "任意图像 + 任意3D模型, 不做传统 RT 标定对齐,
> 考虑非刚性 warp, 自由建立 2D像素↔3D模型↔相机坐标系 的投影映射"
> **作者**: ZCode · 2026-08-04 · 全部组件已有可运行实现与实测 (docs/04/05/06)

---

## 1. 问题重构: 从"标定"到"自由坐标系"

传统 AR 注册的范式是**先标定、再对齐**: 已知内参 K 与世界系定义,
用旋转+平移 (RT) 把模型坐标系对齐到相机坐标系。这个范式有三个隐含假设:
①坐标系可预先标定; ②物体刚性; ③单帧单模型。
用户提出的"自由坐标系"思想, 本质是**废除这些预设**:

```
自由坐标系注册 (Free-Coordinate Registration):
  不预设世界系/标定系, 把问题重构为三个坐标系的【自由联合映射】
      F: (X_m ∈ 模型系) ↔ (X_c ∈ 相机系) ↔ (x_p ∈ 像素系)
  映射 F 的全部参数 (位姿 T、内参 K、形变场 W、尺度 s) 联合可估,
  且每个参数都可独立缺省 (未知内参/未知深度/非刚性/多模型)。
```

**形式化**: 自由映射 `F = π_D ∘ K ∘ (R,t) ∘ (I + W)` 其中
- `π_D∘K`: 成像映射 (透视+畸变), K 可缺省 (DUSt3R/VGGT 估计)
- `(R,t) ∈ SE(3)`: 刚性骨架, 由对应关系+鲁棒求解器估计
- `W`: 形变场 (RTW 的 W), 由可观测性引导的优化估计 (创新点2)

已有方法都不满足"自由"的全部含义: FoundationPose 需已知内参+深度;
DUSt3R 重建场景但不注册外部模型; 医疗导航配准假设刚性+标定。
**FreeReg 是第一个把"自由坐标系"作为第一性原理的系统框架** —— 这就是论文的"故事核"。

## 2. 五个创新点 (均有已实现原型与实测数据)

### 创新点1: 坐标系自由化的统一注册框架 (框架创新)

四种输入模式同一求解内核 (3D-3D 化 + 对应 + 鲁棒求解):

| 输入 | K | 深度 | 路径 | 实测 |
|------|---|------|------|------|
| RGB-D 标定 | 已知 | 已知 | 反投影→ICP | BOP ADD-S AR@10%d=1.00 |
| RGB-D 无标定 | VGGT/DUSt3R | 已知 | K 估计→同上 | VGGT 结果可用 (docs/02) |
| 单目 RGB | VGGT | 点图 | 点图→3D-3D | 接口同构 |
| 双目/立体 | 标定文件 | 立体匹配 | FoundationStereo | SCARED 实测 |

**与 SOTA 区别**: FoundationPose 只解决"模型位姿"一环且需内参;
FreeReg 把内参/深度/位姿/形变纳入**同一参数空间的联合估计**,
各分量缺省时自动降级 (可观测性分析指导, 见创新点2)。

### 创新点2: 可观测性引导的 RTW 分层求解 (理论+方法创新, 核心)

非刚性注册的本质困难是**病态性** —— 我们的实验定量刻画了三类病态:
1. **刚性简并**: 空间平滑低频形变在单视图部分可见下 ≈ 刚性变换
   (实测: 平滑形变下纯刚性残差仅比 RTW 高 26%)
2. **切向不可观**: 单视图深度观测不能约束面内切向位移
   (实测: 全 3D 形变恢复仅 11%, 视线方向分量恢复显著更高)
3. **规范自由度**: 形变场全局刚体分量可被 (R,t) 或 δ 任意吸收

**提出的解法**: 将形变场 W 按**观测算子 J 的奇异结构**分解为
可观测/不可观测子空间: 数据项只作用于可观测分量 (J 奇异值>τ),
不可观测分量由强先验 (平滑/最小形变) 决定 —— 即
**带可观测性投影的正则化 RTW**:

```
min  ρ( J·(R,t,δ_obs) ) + λ·||δ_unobs||²     s.t. δ = δ_obs ⊕ δ_unobs
其中 δ_obs = Proj_{σ_i(J)>τ} δ
```

已有 Embedded Deformation / DynamicFusion 都未做显式可观测性分解。
**这是从我们的实测发现 (docs/04 §4) 上升出的方法学贡献** ——
实验-理论互证, 是审稿人喜欢的故事结构。

### 创新点3: 轮廓门控的对称判别与时序仲裁 (方法创新)

对称物体位姿等价类是 6DoF 估计的公开难题。我们发现并验证:
- 深度一致性判别不可靠 (ICP 收敛翻转拟合同样好, 胜率 5/9)
- **轮廓形状 chamfer 是最强经典判别** (9/9, 正确1.2-1.4px vs 翻转2-4.5px)
- 时序连续性是最强先验 (跟踪 35ms/帧, 0 翻转; 翻转仅发生于全局重注册)

**提出的机制**: 单帧**轮廓仲裁** (多假设+轮廓验证) +
时序**创新门控** (SE(3) Kalman, 离群拒绝滑行, 连续 N 帧才真重定位)
→ 对称物体**无翻转视频注册**。
实测: BOP 125 帧 ADD-S=1.000, 跟踪 28FPS, 门控 0 误触发。

### 创新点4: 注册-渲染共享锚点场 (架构创新)

RTW 的 FFD 控制点 (锚点) **同时**驱动两件事:
① 非刚性位姿精化的形变场 (注册侧); ② 4D 高斯的形变驱动 (渲染侧)。
**一个参数场, 注册与渲染互为验证**:

```
锚点场 A = {δ_j}:  注册: min || obs − Π(RT( V + W(V;δ) )) ||
                  渲染: μ(t) = μ₀ + W(μ₀; δ(t))
副产物: 渲染残差 = 注册精度的【在线无标签验证信号】
       (实测: 深度残差 RMS 与位姿误差强相关 → 可用于触发重注册)
```

实测: 静态 3DGS 44.9dB, 4D 动态渲染大形变下 +2.6dB vs 静态;
渲染残差与形变恢复精度一致 (docs/04 §4, docs/06 §4)。
**与 4D-GS/DynamicFusion 的区别**: 它们估计形变为了重建;
我们把形变作为**注册与渲染的统一参数**, 实现"渲染即可信度"。

### 创新点5: 自由坐标系医疗 AR 导航评测基准 (数据/应用创新)

医疗内窥镜是自由坐标系问题最苛刻的试炼场
(无标定单目、组织非刚性、光照复杂、缺乏 GT)。
我们拥有独特的数据组合 (docs/02):
- SCARED (RGB-D立体+点云+轨迹 GT) —— 已实现 197 帧实拍 AR
- C3VD 结肠 GT 网格 + 真实结肠镜场景 —— 2D-3D 注册 GT
- **省医 30 患者 CT + 支气管镜视频** —— 临床 CT-视频注册 (独家)
- EndoNeRF 形变序列 —— RTW 医疗验证

**贡献形式**: 首个"自由坐标系医疗 AR 注册"系统化评测协议
(靶点定位误差 mm、遮挡正确率、抖动、形变恢复), 计划开源。

## 3. 实验设计 (论文级)

### 3.1 数据集与基线

| 维度 | 数据 | 基线 |
|------|------|------|
| 通用刚性 | BOP LM/T-LESS | FoundationPose, MegaPose, SAM-6D |
| 无标定 | DUSt3R/VGGT 输出 | 原始 DUSt3R+ICP |
| 医疗 RGB-D | SCARED, C3VD | Endo3R, 传统 RT 配准 |
| 非刚性 | EndoNeRF, 合成形变 (本方案协议) | DynamicFusion式 RT-only |
| 临床 | 省医 30 患者 | 人工标记配准 (金标准) |

### 3.2 消融实验 (每个创新点一个 knob)

| 消融 | 验证 |
|------|------|
| w/o 可观测性引导 (全空间 RTW) | 创新点2: 形变恢复↑、过拟合↓ |
| w/o 轮廓仲裁 (仅深度判别) | 创新点3: 翻转率 16%→0 |
| w/o 创新门控 (重置到测量) | 创新点3: 重定位风暴→0 |
| w/o 共享锚点 (注册/渲染分离) | 创新点4: 渲染残差不可作验证 |
| w/o 多源对应 (单引擎) | 创新点1: 成功率 60%→90% |

### 3.3 指标

- 位姿: ADD/ADD-S/AR (BOP 协议), 旋转/平移误差
- 时序: 抖动偏差 RMS(px), ATE (轨迹), 重定位次数
- 渲染: PSNR/SSIM/LPIPS, FPS, 遮挡决策正确率
- 形变: 深度残差 RMS, 形状 Chamfer, 逐顶点恢复 (分可观测性)
- 临床: 靶点配准误差 (mm), 医生主观评分 (Likert)
