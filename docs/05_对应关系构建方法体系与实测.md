## 1. 投影映射方程与"对应"的角色

要求解的方程（以 2D-3D 为例）：

```
x_p,i = π( K · T · X_m,i ),   i = 1..N      未知量: T ∈ SE(3) (6 DoF)
```

**对应关系 {X_m,i ↔ x_p,i} 是把"方程"变成"方程组"的唯一输入**。没有对应，
位姿问题根本不可解；对应的质量（数量/分布/纯度）决定解的质量上限。
三类对应（docs/03 §3.1）：

| 对应类型 | 坐标对 | 求解器 | 最小对数 |
|---------|--------|--------|---------|
| 3D↔3D | 模型点 ↔ 场景点 | Kabsch/Umeyama (闭式) | **3 对非共线** |
| 2D↔3D | 像素 ↔ 模型点 | P3P/EPnP + RANSAC | **3 对 (+1 验证)** |
| 2D↔2D | 像素 ↔ 像素 (跨视图) | 5/8点法求E → 三角化 | **5/8 对** |

深度图把 2D↔3D 提升为 3D↔3D（反投影），所以 RGB-D 下 3D-3D 是主路径。

## 2. 有效对应的三要素与最少条件

| 要素 | 含义 | 不足的临床表现 | 对策 |
|------|------|---------------|------|
| **数量** | 对数 ≫ 最小值 (经验 ≥ 10-20 对) | 解不稳定/多解 | ROI 放大提特征、多假设 |
| **分布** | 覆盖物体各个方向 (非退化构型) | 绕连线方向旋转不可观 | 特征均匀化、多视角参考 |
| **纯度** | 内点率 (RANSAC 后验 ≥ 30-50%) | 收敛到错误一致解 | ratio test、RANSAC、trim、门控 |

**实测 (BOP ape, 12 对人工标记 oracle)**: 仅 12 对高精度对应即可达
**Kabsch 0.84° / PnP 0.87°、1.7ms** —— 说明问题不在求解器，
而在**对应的自动构建**。这正是全部五类自动方法的战场。

## 3. 五类构建方法: 原理、链路与实测

> 实测条件: BOP LM scene 000001 (ape, 部分对称), 10 帧真实 RGB-D,
> 成功判据 rot_err ≤ 10°。完整逐帧数据见文末表格。

### M1 人工/标记点 (金标准上界)
手术导航探针点穴、贴 fiducial 标记。**精度最高 (0.8-0.9°)**, 无法自动化。
用途: 标定、GT 生成、其他方法的精度上界。

### M2 纹理特征对应 (2D-2D → 深度提升 → 2D-3D)

```
查询图 ←SIFT匹配→ 参考图(已知位姿) → 参考像素深度反投影 → T_ref⁻¹ 变换
     → 模型系3D点 ↔ 查询2D像素 → PnP+RANSAC
```

- **关键工程点**: 小目标必须 **ROI 裁剪+放大3×** 再提特征
  (实测关键点 3 个 → 200+ 个, 差两个数量级)
- **实测**: 成功帧 rot_err **1-3°, 10-16ms**; 但**纹理对称时系统性翻转**
  (ape 左眼角点匹配到右眼角点 → PnP 收敛到翻转一致解) → 单用成功率 30%
- 适用: 有纹理、非对称 (或纹理不对称) 物体; 参考照片库可得
  (= FoundationPose model-free / OnePose 的输入假设)

### M3 几何特征对应 (3D-3D, FPFH+RANSAC)

模型点云与场景点云各自计算 FPFH 特征签名 → 特征匹配 → RANSAC 全局配准。
- **实测**: 多数帧 **3-6°**; 对称物体部分翻转 → 成功率 60%, ~250ms
- 适用: 无纹理但几何形状有区分度; 无需初值

### M4 渲染-比较模板 (隐式对应)

```
离线: 测地球面 162 视点渲染模板库
在线: 观测深度 vs 模板相似度打分 → top-K 位姿假设 → ICP 精化
```

- 本质是 FoundationPose 的核心范式: **"哪个渲染视角最像观测"= 隐式 2D-3D 对应**
- **实测**: 命中时 1-5°; 但真实噪声深度下模板排序不稳 → 成功率 30%, ~300ms
- 适用: 无纹理物体、干净数据/合成数据、作为假设发生器
- 升级路径: 模板打分换神经评分器 = FoundationPose 本体

### M5 深度提升直接对应 (2D→3D 反投影 → trimmed ICP)

深度图 mask 区域反投影 → 场景点云 → 最近邻建立 3D-3D 对应 → trimmed ICP。
- **实测**: 需好初值 (多起点兜底), 成功帧 **2-8°**, 成功率 60%, ~650ms
- 适用: RGB-D 主路径; 遮挡多时 trim 比例要调低

## 4. 对称歧义: 三种判别信号的实测对比

对应构建之后, 对称物体仍有多余一致解, 需要**判别信号**仲裁。
在 9 对"ICP 收敛的 正确/翻转 假设对"上实测:

| 判别信号 | 原理 | 实测胜率 | 结论 |
|---------|------|---------|------|
| 深度一致性 (无渲染投影) | 稠密点投影, |z−depth|<5mm 比例 | **5/9** | 被 ICP 优化过的翻转拟合同样好 → 不可靠 |
| **轮廓形状 chamfer** | 渲染轮廓 vs 观测轮廓双向倒角距离 | **9/9** | 轮廓编码朝向语义(耳/面突起), 最强经典信号 |
| IoU (mask 交并比) | 渲染mask∩观测/∪ | (弱) | 辅助项 |

```
正确假设轮廓 chamfer: 1.2-1.4 px    IoU: 0.78-0.87
翻转假设轮廓 chamfer: 2.0-4.5 px    IoU: 0.57-0.75
```

**结论**: 单帧经典方法的判别天花板 = **轮廓形状验证**;
更高层判别需要学习式外观评分 (FoundationPose 神经 scorer) 或时序先验 (§5.3)。

## 5. 工程配方: 多源候选 + 仲裁 + 时序传递

### 5.1 组合管线 (本系统实现, `run_bop_eval.py --engine hybrid`)

```
                    ┌─ M2 SIFT-PnP (有纹理时) ─┐
  RGB-D + mask ─→  ├─ M3 FPFH 全局 ────────────┼─→ 候选位姿集
                    └─ M5 多起点 ICP ──────────┘      │
                                                      ▼
                              轮廓形状 + 深度一致性 仲裁 (arbitrate_poses)
                                                      ▼
                                              trimmed ICP 精化 → T_obj^cam
```

**125 帧真实评测**: ADD-S AR@10%d = **1.000**, ADD AR@10%d = **0.712**
(vs 单一几何引擎 0.648), AR@20%d **0.784** (vs 0.688), 旋转中位 **3.82°**。

### 5.2 对应的纯度工程

- ratio test (0.75-0.8) 剔除 2D-2D 歧义匹配
- RANSAC (PnP) / trimmed ICP (保留 70% 残差最小对应) 抗外点
- 置信加权: 学习法输出的对应置信度直接进入求解器权重
- **门控**: 创新 > 阈值 → 拒绝测量 (时序滤波, 防错误对应污染状态)

### 5.3 时序传递: 对应不必每帧重建

视频场景最高效可靠的"对应"是**上一帧的位姿**：
```
帧 t-1 位姿 → 预测 → 帧 t 只需在小邻域内重新建立对应 (ICP 局部收敛即可)
```
- 跟踪模式实测 **35ms/帧, 0 翻转** (时序连续性天然排除对称跳变)
- 对称翻转只发生在全局重注册时刻 → 用轮廓仲裁 + 创新门控双重把关

## 6. 选型决策表

| 场景条件 | 首选对应方法 | 备选 | 备注 |
|---------|------------|------|------|
| 有纹理非对称物体 + RGB | **M2 SIFT/SuperPoint + PnP** | M4 | 最准最快 |
| 无纹理 + RGB-D | **M3 FPFH + M5 ICP 组合** | M4 | 几何签名主导 |
| 对称物体 (单帧) | 多源 + **轮廓仲裁**, 用 ADD-S 评价 | 学习式 scorer | 经典天花板 |
| 视频序列 | **时序传递对应 (跟踪)** | 定期全局重注册+仲裁 | 35ms/帧 |
| 无纹理无深度单图 | M4 渲染-比较 → 学习引擎 | DUSt3R 点图→M5 | 欠定, 需先验 |
| 医疗内窥镜 | 双目深度→M5 + M2(血管纹理) | Endo3R 点图 | 形变再叠加 RTW |
| 高精度标定场景 | **M1 人工标记** | — | 金标准 |

**一句话回答**: 对应关系的构建没有银弹 —— 有效方案是
*按数据条件选择对应类型 (纹理/几何/隐式), 用 RANSAC/trim 保证纯度,
多源出候选, 轮廓形状+深度一致性仲裁, 视频场景用时序传递代替每帧重建*;
学习式方法 (FoundationPose/DUSt3R) 的本质是把"对应构建与纯度判断"
端到端神经化, 是以上经典配方的原位升级。
