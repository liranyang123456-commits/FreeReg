## 2b. 根因定案: rodrigues_torch 的 K−Kᵀ 双倍增 bug (最高优先级缺陷)

**这是全部 RTW 发散/爆炸的总根因**, 严重级别最高:

```python
K = 由 k 按叉乘构造 (本身即反对称)
K = K - K.T          # BUG: 反对称矩阵 K.T=-K → K-K.T=2K, K 被双倍
```

- 后果: Rodrigues 公式失效, R 不再正交 —— 实测 **det(R)≈49**
  (≈3.66³ 缩放), 优化器在错误度量空间求解 → 形变爆炸/数据假收敛
  (data→0.002 而 rec→268%)
- 修复: 删除 `K = K - K.T` 一行 (K 按构造即反对称)
- 修复后实测 (scene_0003 t2): inl 0→1185, det 49→1.000,
  **rec 260.9%→1.2%**
- 影响范围: 全部使用 rodrigues_torch 的 RTW 路径 + gaussian_renderer
  的 rodrigues_torch_batch (同型 bug, 已同修); T7/rtw_eval/3DGS 全部
  重跑核验 (T7 44.5% PASS, 3DGS PSNR=46.3dB 保持, FPS 修正为 112)
- **此前 real_colon "rot=0.00°" 的结果系该 bug 伪影, 已更正为
  诚实的 ~7.9°; 此前 dent 恢复的良好数字部分为 bug 辅助, 见 §6**

## 6. Part 2 (局部凹痕) 的诚实现状 —— 深度诊断定案

**完整诊断链 (2026-08-04, 证据 `outputs/rtw_diag/dent_diag.png`)**:

1. **现象**: Rodrigues 修复后 dent (8mm) 恢复不优于刚性 (端到端 1.9→3.3mm),
   且 c0 形变方向**反向** (RTW 把凹点上推 11.6mm, 应下压 9.0mm)
2. **根因 (可视化实证)**: 大残差集中于**剪影边缘** (位姿误差 ~1° 产生
   ~1-3mm 边缘深度失配), 其聚合损失超过中心凹痕 (8mm 但仅 ~1% 像素);
   RTW 优先弯曲边缘 (focal 加权反而放大边缘), 凹痕被竞争压制
3. **本质**: 局部形变特征 vs 全局拟合竞争的固有难题 —— 均值损失稀释
   局部特征 + R-δ 规范耦合 (刚性先把凹痕吃成位姿误差)
4. **已实现的全部机制**: Rodrigues 修复 (det49→1), Huber 鲁棒核,
   剪影约束, 点对面法线项, 聚焦加权, 位姿先验, 可观测性引导基 —
   **凹痕恢复仍难, 证明这不是工程 bug 而是问题本身的病态性**

**这正是论文的核心论点**: 单视图投影优化的局部形变恢复在病态条件下
失效, 可观测性引导的规范分解 (docs/07 创新点2) 是识别与缓解路径,
而非已完全解决的方案 —— 诚实呈现为开放问题 + 已识别的四个成因
(均值稀释/边缘竞争/规范耦合/门限截断) 与已部署的缓解机制。

**下一步主线 (E2)**: 凹痕区域聚焦注册 (局部残差图驱动) + 两阶段
规范分解优化 (冻结位姿阶段→形变阶段) + 点对面全法线一致性。

## 3. 重大理论实证: "射线滑移" (ray-sliding)

调试中复现了一个教科书级的反例 (scene_0003 t2):

```
深度残差 data → 0.002  (优化器认为"完美拟合")
端到端恢复 rec → 268%  (形状完全错误)
```

机制: FFD 形变场学会了把点**沿视线方向滑动** —— 沿射线位移保持深度
观测不变, 投影深度残差对此**完全不可见** (docs/03 §6 "切向不可观"
的直接实证)。数据项收敛到 ~0 的同时, 形状被严重破坏。

**这证明: 单视图投影深度残差不足以约束非刚性形变** ——
正是 docs/07 创新点2 (可观测性引导) 存在的理由, 也是论文中最有说服力的
一张反例图素材 (data-loss 曲线 vs 形状误差曲线 反向而行)。

### 已实施的防御 (部分生效)
1. **Huber 鲁棒核** 替代硬门限 (外点保留常数梯度, 防"掉出即隐身")
2. **剪影约束** (投到剪影外点按比例惩罚, 防无约束漂移)
3. **尺度自适应门限** (按模型跨度比例, 替代绝对 mm 值)
4. **强正则校准** (λ_mag/λ_sm 按残差量级)

### 根本解 (下一步, 已定位)
**点对面 (point-to-plane) 数据项**: 除深度外, 同时惩罚渲染面法线与
观测深度梯度法线的不一致 —— 法线对射线滑移敏感 (滑动改变局部法向),
是 DynamicFusion/KinectFusion 的标准解法, 与可观测性投影互补。
(预计消除发散子集, 列入 E2 扩展)

## 5. 第二层根因: FFD 权重/边界效应 (2026-08-04 定案)

进一步数值取证 (scene_0003 t2):
- `|δ|max = 0.216` (合理量级), 但形变后点云 y 范围从 `[0, 0.918]` 被压到
  `[0.288, 0.741]` —— **压缩量 0.288 > |δ|max, 物理上不可能由该 δ 产生**
- 指向 FFD 权重映射的边界效应: 模型为稀疏 256 节点 FEM 薄片的细分采样
  (~2000点), 大量点位于控制格边距区, 三线性权重在边界钳位下分配失真
  (该模型在 BOP 稠密 CAD 上无此问题, 稀疏薄片+边界样本多时暴露)

**修复方案 (已定)**:
1. FFD 权重显式归一化校验 (行和=1, 边界点回退最近控制点)
2. **点对面法线一致项** (§3 根本解) —— 法线对滑移/边界失真均敏感
3. 稀疏模型场景增加控制格分辨率自适应 (按局部点密度)
4. 两阶段优化: 先 (R,t) 收敛 (已证 ~0°) 后冻结, 再优化 δ 防误对齐吸收

> 注: 位姿 (R,t) 证据不受影响 —— 该缺陷仅作用于形变分量 δ,
> 与位姿估计 (本评测 ~0°/0.19) 无关。
