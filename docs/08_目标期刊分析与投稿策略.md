## 2. 分层投稿策略 (修订版, 基于现有证据)

### 判定逻辑 (重要)

docs/13 初稿的三个卖点排序:
1. **SOTA 在医疗内镜失效 (FP 104mm) + 我们完胜 (TRE 4.2mm, p=4.4e-31)**
   → 方法-应用故事, 医疗影像期刊吃这套
2. **全链路系统 (对应→RTW→时序→3DGS渲染) 的可复现工程**
   → 系统期刊吃这套 (TVCG/CBM)
3. **可观测性分解理论 (151/648)** → 方法学期刊加分项 (MedIA/TMI)

### 首选 —— **Computers in Biology and Medicine (CBM, IF≈7)** ⭐推荐

| 项 | 评估 |
|----|------|
| 适配度 | ★★★★★ (方法+系统+临床统计正是其 scope) |
| 现有证据是否够 | **够** —— 12例统计+SOTA对比+完整消融, 无需补实验即可投 |
| 难度 | 中高 (比 TMI 现实一档) |
| 周期 | 4-8 月 |
| 卖点匹配 | 卖点1+2+3 全部吃得下 |
| 风险 | 低-中; 真实视频 GT 缺失可作为"future work"声明 |

### 次选 —— **IEEE TVCG (IF≈4.7)**

| 项 | 评估 |
|----|------|
| 适配度 | ★★★★ (MR 系统+渲染主线: 3DGS 46.6dB/4D 锚点/场景图) |
| 需要补强 | 渲染侧实验 (用户感知研究/更多场景), 医疗叙事弱化 |
| 周期 | 4-8 月 |
| 备注 | 若作者更认同"MR 系统"身份, 与 CBM 并列首选 |

### 冲顶 —— **IEEE TMI (IF≈10) / MedIA (IF≈11)**

| 项 | 评估 |
|----|------|
| 适配度 | ★★★★ (主题完全契合) |
| **硬门槛** | 真实视频人工 GT (双人复核) + 队列≥15 + 多中心更佳 |
| 建议路径 | **不直接投**: 先 MICCAI'27 短文 (3月窗) 建优先权 → 补 GT 扩队列 → TMI 扩展版 |
| 风险 | 现在直投, 大概率"临床验证不足"被拒 |

### 稳妥快 —— **IJCARS (IF≈2.3) / IEEE Access (IF≈3.4)**

- IJCARS: 手术导航社区, 现有临床统计足够, 3-6 月, 适合快速占位;
- IEEE Access: 1-3 月, 仅在竞品压力下使用。

### 会议路径 (联动)

| 会议 | 时间窗 | 策略 |
|------|--------|------|
| **MICCAI'27** | 2027年3月 | 短文 (SOTA失效故事+12例统计) → TMI 扩展 |
| **IPCAI'27** | 2027年10月 | 临床导向短文 |
| **CARS'27** | 2027年1月 | 快速临床展示 |

```
是否愿意再投入 2-3 个月做真实视频人工 GT?
├─ 不愿意/要快 → CBM 直接投 (证据已够) ⭐

├─ 愿意少量投入 (1-2周标注+复核) → CBM 投 + 同步准备 TMI 扩展

    → 补 GT + 队列≥15 → TMI (2027 底-2028)
```

**我的具体建议 (基于证据现状)**:
1. **立刻**: 按 docs/13 完善图件 → **投 CBM** (现有证据已充分, 周期适中);
2. **并行**: 做真实视频人工 GT (中心线提案+双人复核, ~2周),
   无论 CBM 结果如何, 都是 TMI 扩展版的硬通货;
3. **2027.3**: MICCAI 短文占位 (SOTA 失效故事是天然好故事);
4. **若 CBM 被拒**: 按意见修改 → IJCARS (快) 或 TVCG (转渲染叙事)。
