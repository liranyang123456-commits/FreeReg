# 真实视频人工 GT 制作工作流 (中心线提案 + 双人复核)

> **目标**: 为省医真实支气管镜视频建立 CT-视频注册评测 GT (TMI 硬通货)。
> **方法**: 半自动 —— 本管线先生成提案对齐, 双人独立标注解剖标志点,
> 共识合并, 再用 GT 地标评测注册重投影误差。
> **日期**: 2026-08-04 · 状态: 工具链已就绪并端到端验证

---

## 0. 为什么这样设计 (而非直接标位姿)

CT-视频注册的 GT 无法直接"画出 4×4 位姿" —— 可行的文献做法
(C3VD/电磁导航验证) 是**解剖标志点 GT**:
对选定帧, 标注 "视频中的解剖点 (2D) ↔ CT 中的对应点 (3D)" 的对应关系,
再用 ①注册位姿把 3D 点投影回图像, 与 2D 标注的像素差作指标
(重投影误差, 临床可解释: 误差 < 10-20px ≈ 亚毫米-毫米级)。

半自动的必要性: 纯手工逐帧标注数百帧不可行;
管线提案 (中心线注册, docs/10 E1.5) 先把对齐做到 ~85%,
人工只做"确认/纠正标志点", 效率提升 ~10×, 且双人可独立复核。

## 1. 三件套 (已实现, 全部可运行)

```
① scripts/run_gt_gtprep.py   提案包生成 (20帧, ~70s)
   输出 outputs/gt_pkg/: frames/ overlays/ ct_junctions.csv frames.csv README.txt

② scripts/run_gt_annotate.py 双人交互标注 (cv2 窗口)
   python scripts/run_gt_annotate.py --reader R1
   python scripts/run_gt_annotate.py --reader R2
   键位: 左键=标点; 空格/n=下一张; b=上一张; s=跳过; u=撤销;
        1-5=标签(1隆突 2右主 3左主 4右叶 5左叶); q=保存
   输出 annotations_R1.csv / annotations_R2.csv

③ scripts/run_gt_consensus.py 共识合并+评测
   python scripts/run_gt_consensus.py
   规则: 同帧同标签 |Δ|≤15px → 均值作GT; 否则标记仲裁
   输出 gt_landmarks.csv + 一致性统计 + 注册重投影误差
   (--demo 合成双人端到端验证: 已验证 100%一致, 偏差6.6px)
```

## 2. 操作流程 (实际执行)

1. **生成提案包** ✅ 已完成 (`outputs/gt_pkg`, **100 帧**, 001 患者视频
   全程 5%-90% 覆盖, chamfer 16-59px; 可用 `--n/--start/--end` 任意扩)
   - overlay 图: 绿=图像管腔骨架, 红=投影 CT 中心线, 黄圈=CT 分叉点
2. **双人独立标注** (待人工, 大屏+放大镜版已就绪):
   - 阅片者 A: `python scripts/run_gt_annotate.py --reader R1`
   - 阅片者 B: `python scripts/run_gt_annotate.py --reader R2`
   - **放大镜**: 鼠标移动即跟随放大光标邻域 (z开关, +/-调2-8x);
     自动全屏 (f切换); **每条即时落盘防丢失, 断点续标**
   - 键位: 左键标点; 空格/n下张; b上张; s跳过; u撤销; 1-5标签; q保存
3. **共识合并**: `run_gt_consensus.py`
   - 自动报告双人一致率/偏差; |Δ|>15px 的点列仲裁清单 (第三人裁定)
4. **评测接入**: 重投影误差自动计算 (提案位姿 → GT 地标);
   可对比本管线/FP/Endo3R 在同帧的误差, 配对 Wilcoxon。

> **目标期刊: IEEE TBME (二区TOP)** —— 真实 GT 是其关键门槛;
> 100 帧双人 GT + 重投影误差 + 分解剖层统计 即为 TBME 级证据。

## 3. 质控与扩展建议

- **一致性门限**: 默认 15px (1920×2400 视频 ≈ 0.6% 画幅, 可调)
- **仲裁**: 第三人 (高年资) 裁定分歧点, 记录三方决议
- **扩展队列**: 同一流程跑 002/008/其他患者视频 → 多患者 GT
- **解剖覆盖**: 帧采样已覆盖隆突/主支气管/叶支气管层级;
  建议每层 ≥5 帧以便分层统计
- **报告指标**: 重投影误差 mean/中位 + 双人一致性 +
  分解剖层误差 (carina vs lobar) —— TMI 审稿标准配置
- **效率参考**: 提案对齐 chamfer ~23px (好帧) / ~59px (弱帧);
  弱帧建议多标人工点以主导共识
