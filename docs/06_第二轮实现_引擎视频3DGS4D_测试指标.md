## 1. 位姿引擎升级 (替代经典几何基线)

### 1.1 架构 (`src/render_compare_engine.py` + `src/appearance_engine.py`)

```
RGB-D + mask
   ├─ M2 SIFT纹理对应 (ROI裁剪放大3×, 参考库40帧) → PnP+RANSAC
   ├─ M3 FPFH 全局配准 → ICP
   ├─ M5 多起点 ICP
   └─ M4 渲染-比较模板库 (162测地视点, GPU批量打分) → top-K → ICP
                    │
                    ▼
        候选集 → 轮廓形状+深度一致性 仲裁 (arbitrate_poses)
                    ▼
              trimmed ICP 精化 → T_obj^cam
```

**FoundationPose 适配**: `PoseEngine(backend=...)` 接口与 FP 输出同构
(4×4 位姿), 官方权重就位后原位替换假设生成/评分环节。

### 1.2 BOP LM 全量评测对比 (5场景×25帧 = 125样本)

| 指标 | classic (几何双引擎) | **hybrid (本方案)** | 变化 |
|------|---------------------|---------------------|------|
| ADD-S AR@10%d | 1.000 | **1.000** | — |
| ADD-S AR@5%d | 0.880 | **0.912** | ↑ |
| ADD AR@10%d | 0.648 | **0.712** | ↑10% |
| ADD AR@20%d | 0.688 | **0.784** | **↑14%** |
| 旋转误差中位 | 4.11° | **3.82°** | ↓ |
| 重投影RMSE中位 | 3.09px | **2.77px** | ↓ |
| 单帧耗时 | 0.84s | 1.44s | 仲裁渲染开销* |

\* 提速路径已明确: 双引擎一致时跳过 SIFT/轮廓仲裁 (多数帧) → 预计 ~0.6s;
视频跟踪模式恒 35ms。对称真旋转对称物体 (bowl/can) 的残余翻转属协议内
歧义, 以 ADD-S 评价; 根本解为 FP 神经评分器 (接口已备)。

### 1.3 对称歧义判别信号实测 (docs/05 §4)

| 信号 | 胜率 (9对收敛假设) | 结论 |
|------|------------------|------|

## 3. 3DGS 渲染器 (M4)

`src/gaussian_renderer.py` — Kerbl'23 的 torch 参考实现:
EWA 投影 (Σ_2d = JΣJᵀ) + 稀疏(高斯,像素)对枚举 + 按(像素,深度)排序
分段 cumsum 前向透过率 + index_add 混合。**全向量化、全可微**。

### 3.1 关键 bug (已修复)

1. **段索引映射错误**: `cum_before = before[seg_id]` 把段号当泼溅索引
   → 透过率全错 (渲染近黑); 修正为 `seg_start_cum[seg_id]` —— 2高斯
   受控测试精确定位 (期望值 vs 实测逐分量吻合)
2. **fp32 全局 cumsum 精度灾难** (~1e6 幅度, 段内差分被量化吞掉) → fp64
3. **背景剩余透过率用全局 cum 而非段总和** → 背景丢失

### 3.2 指标 (pseudo-GT=20k稠密泼溅, 5视角, duck)

| 视角 | PSNR 硬泼溅(4k) | PSNR 3DGS(4k,训练4视角) | SSIM 泼溅 | SSIM 3DGS |
|------|----------------|------------------------|----------|-----------|
| train1-4 | 36.9-37.3 | **46.3-48.8** | 0.933-0.938 | **0.992-0.996** |
| **test (未训练)** | 37.2 | **42.6** | 0.932 | **0.982** |
| 平均 | 37.1 | **46.6 (+9.5dB)** | 0.937 | **0.992** |

- **渲染速度: 5ms/帧 = ~200 FPS** (640×480, 4000高斯, torch 参考实现)
- 训练: 300 iters / 16s (4视角, 320×240)
- 官方 CUDA tile-based 版 ~100+ FPS@百万高斯 (接口同构, 可原位替换)

## 4. 4D 动态渲染 (M5)

`scripts/run_4dgs_eval.py` — 架构: 静态3DGS + FFD形变场(**锚点=控制点**)
→ 每帧 μ(t) = μ₀ + W(μ₀)·δ(t) (协方差近似冻结, 小形变假设)

| 动态帧 (前景PSNR) | 静态模型→动态GT | **4D渲染→动态GT** | 增益 |
|------------------|----------------|------------------|------|
| t1 横向弯曲 12mm | 26.75 dB | **29.38 dB** | **+2.6 dB** |
| t2 局部凹痕 10mm | 29.35 dB | 29.38 dB | ≈0* |

\* 凹痕以深度方向为主, 静态即可近似; 增益随横向形变增大而显著。
**局限**: 协方差冻结 (未随 FFD 雅可比旋转), 大形变区表示误差增大;
GT 拉伸采样空洞 —— 已记录; 升级为每高斯旋转场/神经形变网络 (真 4D-GS)。
静态 3DGS 基线: 44.9dB (表示上限)。

## 5. 本轮修复的 7 个关键问题 (工程教训沉淀)

| # | 问题 | 根因 | 修复 |
|---|------|------|------|
| 1 | SCARED 轨迹爆炸 (帧间300mm) | **单位误判**: pose 已是毫米, 误乘1000 | 单位核验为第一纪律 |
| 2 | 3DGS 渲染全黑 | 段索引映射 bug + fp32 精度灾难 | 2高斯受控测试定位 |
| 3 | Kalman 速度发散 | 旋转速度噪声与平移同参数量级差10³ | 分离 vel_pos/vel_rot |
| 4 | 深度判别对对称失效 | ICP收敛翻转拟合同样好 | 轮廓 chamfer (9/9) |
| 5 | SIFT 全失效 | 小目标全图关键点仅3个 | ROI裁剪放大3× → 200+ |
| 6 | 渲染-比较模板排序乱 | 错误缩放物体尺寸 (尺度混淆) | 纯平移对齐 |
| 7 | 4D 形变不可见 | 形变沿视线+PSNR背景稀释 | 横向形变+前景PSNR |
