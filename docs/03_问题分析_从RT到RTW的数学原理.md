## 1. 投影映射的完整数学链条

### 1.1 四个坐标系与三条变换

"3D模型注册到图像"涉及 **4 个坐标系、3 条变换**，完整链条为：

```
 模型坐标系 {M}        世界坐标系 {W}        相机坐标系 {C}         像素坐标系 {P}
  X_m ∈ R³   ──T_wm──▶  X_w ∈ R³   ──T_cw──▶   X_c ∈ R³   ──K,π,D──▶  x_p ∈ R²
   (CAD顶点)            (AR锚点系)              (光心为原点)            (图像像素)
```

| 变换 | 数学对象 | 自由度 | 来源 |
|------|---------|--------|------|
| `T_wm`：模型→世界 | SE(3) + 尺度 s | 6(+1) | 用户放置 / 场景图 |
| `T_cw`：世界→相机 | SE(3)（外参） | 6 | SLAM/VIO/DUSt3R |
| `K,π,D`：相机→像素 | 内参+透视投影+畸变 | 5~14 | 标定 / VGGT估计 |

合成一条链：**像素 = π_D( K · T_cw · T_wm · X_m )**。

对 AR 而言，真正要求解的是 **模型→相机的合变换**：

```
T_cm = T_cw · T_wm   ∈ SE(3)
x_p  = π_D( K · T_cm · X_m )
```

单目单图场景下世界系可以省略（取相机系为世界系），问题退化为 **直接估计 T_cm ∈ SE(3)**——这正是 6DoF 物体位姿估计（BOP 基准的标准任务）。

### 1.2 正问题与逆问题

| 方向 | 名称 | 公式 | 用途 |
|------|------|------|------|
| 3D→2D | 投影 (projection) | `x_p = π(K·X_c)` | 渲染、误差计算 |
| 2D→3D | 反投影 (back-projection) | `X_c = z·K⁻¹·[u,v,1]ᵀ` | 深度图→点云 |
| 2D+2D'→3D | 三角化 (triangulation) | 双视图几何 | 立体匹配、SfM |

**关键事实**：透视投影 π 丢失一维（深度 z）。因此"任意单张图像 → 3D 注册"在数学上是**欠定问题**，必须引入额外信息才能闭合链条：

- **深度传感器 / 双目立体**（SCARED、BOP RGB-D）→ 直接补回 z；
- **单目深度估计**（Depth-Anything-V2）→ 预测 z（有尺度歧义）；
- **3D 模型的形状先验**（已知 CAD）→ 用模型几何约束 z（PnP 的本质）；
- **时序多视角**（视频 + SLAM/SfM）→ 三角化恢复 z。

本项目的管线设计（`src/pipeline.py`）就是这四条路径的统一接口。

### 1.3 误差在哪一环产生

| 环节 | 误差源 | 传播到像素的表现 |
|------|--------|-----------------|
| K 估计 | 焦距错 1% | 投影偏移 ≈ 1% 像距 |
| T_cm 旋转 | δθ | 偏移 ≈ f·δθ·(深度差/深度) |
| T_cm 平移 | δt | 偏移 ≈ f·δt/z（近处放大） |
| 深度 z | δz | 反投影点漂移，ICP 误对应 |
| 畸变 D | 未校正 | 边缘像素扭曲（广角/内窥镜显著） |

→ 所有误差最终都以 **重投影误差（reprojection error, 像素）** 为统一度量，这也是本项目评测的核心指标之一（`src/metrics.py`）。

## 2. 成像中的各类变换：透视/仿射/畸变的准确位置

用户提到"成像过程中涉及仿射变换、透视变换"。需要精确区分——它们不是并列的备选方案，而是**链条上不同位置的变换或近似**：

### 2.1 透视投影（真实物理模型）

```
π:  (X, Y, Z) ↦ (fx·X/Z + cx,  fy·Y/Z + cy)
```

- 真实相机的成像模型（针孔），**非线性**（除以 Z）；
- 是投影映射问题的主变换，PnP、Bundle Adjustment 都在此模型上求解。

### 2.2 仿射变换（透视的局部线性近似）

弱透视/正投影近似：当物体深度变化 ΔZ ≪ 平均深度 Z₀（远处小物体）时，

```
π(X) ≈ (fx·X/Z₀ + cx, fy·Y/Z₀ + cy)   ← 关于 X 是线性的
```

- **仿射相机** = 平行投影，把 SE(3)+透视 的 6DoF 非线性问题线性化；
- 用途：①初始化（先解仿射再迭代到透视）；②跟踪小块区域（KLT 光流的局部模型）；③NRSfM（非刚性 SfM）大量工作建立在正投影假设上；
- **局限**：近场、大景深场景误差大——医疗内窥镜（z∈[5,100]mm）不能用仿射近似，必须全透视。

### 2.3 镜头畸变（像素系的径向/切向扰动）

```
x_distorted = x·(1 + k1·r² + k2·r⁴ + k3·r⁶) + 切向项(p1,p2)
```

- 与透视**复合**（先透视归一化，再施加畸变，最后乘 K）；
- 内窥镜广角镜头 k1 可达 -0.3 量级，边缘像素偏移数十像素，**必须先校正**（SCARED 标定文件 `D1` 给出 5 系数，OpenCV 模型，`src/geometry.py: project/distort` 完整实现）。

### 2.4 单应变换 H（特殊的平面情形）

当场景是**平面**（或纯旋转相机）时，两视图间的像素映射是 3×3 单应矩阵 H（8DoF）：

```
x' ~ H·x,   H = K(R - t·nᵀ/d)K⁻¹
```

- 是透视投影在平面约束下的退化形式，AR 平面锚定（把虚拟物体贴到桌面/墙面）直接用 H；
- 棋盘格标定（张正友法）正是利用 H 求 K——本项目 `E:\MIS_Datasets\chessboard\` 的 GT 位姿即由此类方法获得。

### 2.5 小结：一张图看清各自位置

```
X_m ──SE(3) 刚体──▶ X_c ──透视 π──▶ 归一化平面 ──畸变 D──▶ ──K──▶ 像素
        ▲                ▲(ΔZ≪Z₀ 时近似为仿射)      ▲平面场景两帧间由 H 联系
        └──非刚性时: SE(3) ⊕ 形变场 W（即 RTW，见 §5）
```

## 3. 核心问题：两个坐标系如何建立联系

用户的判断完全正确：传统方法是"**分别采集两个坐标系中同一个物体的坐标，然后计算 RT**"。把这思想一般化，所有坐标系配准方法都可以分解为**统一的三段式**：

```
 ① 对应关系建立 (Correspondence)  →  ② 求解器 (Solver)  →  ③ 鲁棒估计+精化 (Robust/Refine)
```

### 3.1 对应关系的三种类型

| 类型 | 对应 | 求解问题 | 典型方法 |
|------|------|---------|---------|
| **3D↔3D** | 模型点 ↔ 场景点云 | 绝对定向 (absolute orientation) | Kabsch/Umeyama、ICP、FGR |
| **2D↔3D** | 图像像素 ↔ 模型点 | PnP (Perspective-n-Point) | P3P+RANSAC、EPnP、UPnP |
| **2D↔2D** | 像素 ↔ 像素（跨视图/跨模态） | 对极几何/单应 | 8点法、5点法、光流 |

深度图把 2D↔3D 提升为 3D↔3D（反投影），所以 **RGB-D 配准 = 3D-3D 问题**，可用 ICP 系列——这是本项目 RGB-D 主路径（`src/pose_estimation.py`）。

### 3.2 对应关系从哪来（由人工到学习的谱系）

| 方式 | 代表 | 特点 |
|------|------|------|
| 人工采集标记点 | 手术导航探针点穴 | 最准，不可自动化 |
| 人工设计特征 | SIFT/ORB/SuperPoint 匹配 | 需纹理，2D-2D/2D-3D |
| 几何最近邻 | ICP 的 NN 对应 | 需好初值，3D-3D |
| 渲染-比较 | FoundationPose/MegaPose | 学"哪个渲染视角像当前图"→ 隐式对应 |
| 点图回归 | DUSt3R/MASt3R/VGGT | **直接回归像素↔3D 点图**——把对应关系本身神经网络化 |
| 语义分割+模型库 | SAM-6D | mask 给出"哪个像素属于哪个模型"→ 粗对应 |

**洞察**：DUSt3R 的本质是把"对应关系建立"从手工特征升级为可学习回归；FoundationPose 的本质是用渲染图像与观测图像的神经特征比对来隐式建立 2D-3D 对应。**整个坐标系联系问题，现代方法都在攻"对应关系"这一关**，因为求解器（PnP/Kabsch/ICP）早已成熟。

### 3.3 鲁棒估计

真实对应必含外点（错误匹配、遮挡、动态物体），标准配置：

- **RANSAC 族**：随机采样最小集 → 假设 → 内点计数（PnP/P3P、基础矩阵的标配）；
- **Trimmed ICP**：每次迭代只保留残差最小的 ξ% 对应，抗遮挡（本项目实现，`trim_ratio` 可调）；
- **鲁棒核**：Huber/Tukey 替代 L2，抑制大残差；
- **置信加权**：学习法输出的对应置信度直接进权重。

## 4. RT 求解器体系（刚性）

### 4.1 3D-3D：Kabsch / Umeyama（闭式解）

给定 N≥3 对非共线对应点 {p_i ↔ q_i}：

```
min_{R,t,s} Σ_i || s·R·p_i + t − q_i ||²
```

闭式解：去质心 → 互协方差 H = PᵀQ → SVD: H = UΣVᵀ → R = V·diag(1,1,det(VUᵀ))·Uᵀ。
Umeyama 版本额外给出尺度 s（模型单位≠场景单位时必需，如 mm vs m）。
**本项目实现**：`src/pose_estimation.py: kabsch_umeyama()`，合成数据验证误差 < 1e-10（见 docs/04）。

### 4.2 3D-3D 无初值对应：ICP

对应未知时交替优化：①当前位姿下找最近邻对应；②Kabsch 更新位姿。局部收敛、需粗初始化。
本项目实现**多起点粗配准 + trimmed point-to-plane/point ICP 精化**两级结构（`src/pipeline.py: coarse_to_fine_register`）：

```
粗: 质心对齐 + 24 个规范旋转（立方体对称群）多起点 ICP → 取残差最小
精: trimmed ICP（残差 70% 分位截断）→ 收敛
```

### 4.3 2D-3D：PnP 家族

| 求解器 | 最小点数 | 特点 |
|--------|---------|------|
| P3P + RANSAC | 3(+1验证) | 最小解，RANSAC 内层 |
| EPnP | 4 | O(n) 线性复杂度，最常用 |
| UPnP | 4 | 支持非透视（广义相机） |
| SQPnP | 4+ | 2022 SOTA，全局最优保证 |
| LM/VVS 精化 | — | 高斯-牛顿/虚拟视觉伺服迭代 |

调用约定：`cv2.solvePnPRansac(EPnP) → solvePnPRefineLM`（`src/pose_estimation.py: pnp_ransac()`）。

### 4.4 2D-2D：对极几何与三角化

8点法/5点法求 E/F → 分解出 R,t（平移仅方向，**尺度不可恢复**——单目 SLAM 的固有歧义）→ 三角化得 3D。这是单目视频路径（ORB-SLAM3/DUSt3R）的数学基础。

## 5. 从 RT 到 RTW：非刚性形变建模

### 5.1 RT 失效的数学本质

RT 假设 **刚性约束**：模型任意两点间距离在变换下不变（等距同构）：

```
∀ i,j:  ||T(p_i) − T(p_j)|| = ||p_i − p_j||
```

非刚性物体（组织形变、软组织、关节运动）违反该约束。强行用 RT 拟合的后果：
- 残差被"平均摊派"到 R,t 上 → 位姿本身被拉偏；
- 重投影误差下不来 → 渲染边缘错位、AR 漂浮感；
- 在医疗内窥镜（组织呼吸/器械推挤形变）中这是**主要误差源**，不是次要修正。

### 5.2 RTW 的统一形式：刚性 ⊕ 形变场

```
T_RTW(p) = R·( p + W(p; θ_w) ) + t
           └──────┬──────┘
        形变后模型点（模型系内先形变，再刚体变换）
```

W 是参数化形变场，θ_w 是其参数。**W 的参数化方式决定问题的可解性与效率**，主流三族：

| 形变模型 | 参数 | 自由度 | 适用 |
|---------|------|--------|------|
| **FFD 自由形变**（B样条/三线性控制格） | 控制格点偏移 δ ∈ R^{M×3} | 3M（M≈4³~8³） | 全局平滑形变，医疗组织 ✅ 本项目 |
| **嵌入变形图 Embedded Deformation Graph**（Sumner'07） | 图节点 {g_j, A_j} ∈ SE(3)×G | 12G | 大局部形变、关节 |
| **TPS 薄板样条** | 控制点位移 + 弯曲能量 | 3M+6 | 稀疏对应驱动、2D-3D 配准 |

三者都是"**少量控制参数 + 插值权重**"的线性混合蒙皮（LBS）思想：

```
W(p_i; θ_w) = Σ_j w_ij · δ_j      (w_ij: 三线性/TPS/测地线权重, 形变前一次性计算)
```

→ 形变后顶点 = 控制参数的**线性函数**，对优化极其友好（`src/nonrigid_rtw.py` 用 torch 自动微分 + CUDA 实现 FFD 版本）。

### 5.3 RTW 的目标函数

```
min_{R, t, {δ_j}}   Σ_{i∈对应} ρ( || R(p_i + Σ_j w_ij δ_j) + t  −  q_i || )   ← 数据项（3D-3D 或重投影 2D-3D）
                  + λ_mag  Σ_j ||δ_j||²                                      ← 形变量正则
                  + λ_sm   Σ_{(j,k)∈邻} ||δ_j − δ_k||²                       ← 形变平滑正则（控制格相邻）
```

- 数据项：RGB-D 下用 point-to-plane Chamfer（渲染深度 vs 观测深度亦可）；
- 正则项不可或缺——形变自由度远大于观测数，无正则则病态（见 §6）；
- 求解：Adam/L-BFGS（自动微分）或高斯-牛顿（解析雅可比）。本项目用 torch Adam，~1s/帧（CUDA）。

### 5.4 与成像变换的关系

注意区分两类"warp"：
- **图像域 warp**（2D）：单应/光流/BSpline 图像配准——作用在像素平面；
- **模型域 warp**（3D）：本节 RTW——作用在 3D 模型，再经透视投影成像。

AR 注册需要的是后者：形变发生在 3D，投影保持针孔模型不变，**渲染无失真**才有几何保证。2D warp 只能做"看起来对齐"的事后修补，会破坏遮挡/深度一致性。

### 5.5 学习式非刚性（延伸）

- **NRSfM**：单目视频恢复非刚性形状（正投影假设多，病态强）；
- **4D Gaussian Splatting / Dynamic 3DGS**：把场景表示为高斯 + 时变形变场，渲染即配准；
- **EndoNeRF 类**： canonical 空间 + 形变 MLP（`E:\MIS_Datasets\EndoNeRF\` 数据可直接验证）。

这些是 RTW 思想的神经化延伸，列入路线图 M5。

## 6. 可观测性、病态条件与正则化

| 问题 | 最小条件 | 病态情形 | 对策 |
|------|---------|---------|------|
| Kabsch 3D-3D | 3 对非共线点 | 点共面/共线 → R 奇异 | 检查 H 秩；SVD 反射修正 |
| PnP 2D-3D | 3 点(P3P)/4点(EPnP) | 点共面+远场 → 深度歧义 | 多假设+RANSAC；加深度 |
| 单目 2D-2D | 5/8 对点 | 纯旋转 → E 退化 | 单应切换；IMU 辅助 |
| 尺度 | 单目不可恢复 | — | 双目/RGB-D/已知物体尺寸 |
| **RTW 形变** | 数据≪自由度 | 欠约束恒成立 | λ_mag/λ_sm 正则；控制格降维 |
| 对称物体 | — | 位姿等价类 | ADD-S 指标；对称感知损失 |
| 时序 | — | 逐帧独立 → 抖动 | SE(3) Kalman + 轨迹正则 |

**深度优先原则**：只要条件允许就用 RGB-D/双目把问题升为 3D-3D——可观测性最好、求解器最稳。单目 2D 路径仅在无深度时启用，并用模型形状先验（PnP）+ 时序先验（Kalman）补约束。

## 7. 时序维度：动态变化无失真

视频注册的增量问题不是"每帧重解"，而是**状态估计**：

```
状态:   x(t) = [ξ(t), v(t)]  ∈ se(3) × R⁶      （位姿李代数 + 速度）
预测:   ξ(t+1) = ξ(t) ⊕ v(t)·Δt                 （匀速运动模型）
更新:   innovation = log( T_meas · T_pred⁻¹ )   （流形上求差）
        标准 Kalman 增益融合
```

要点（`src/se3_kalman_filter.py` 已实现，docs/04 给像素级验证）：
- **在 SE(3) 流形上运算**，避免欧拉角奇异与旋转插值错误；
- 创新过大触发**重定位**（重新全局注册，防跟踪丢失后永久漂移）；
- 离线可用**轨迹正则**（速度/加速度平滑项）进一步压抖；
- 非刚性场景把 δ_j（形变参数）并入状态向量，同一框架滤波。

**与 SOTA 的衔接**（设计文档 docs/01 的角色不变）：
